# NETWORKWALKS-B083-WK3-CYBERSECURITY-PASSWORD-CRACKING
 
Week 3 cybersecurity labs focused on password security — covering hash extraction from password-protected PDFs and dictionary attacks using John the Ripper and Networkwalks' web-based tools.
 
## 📖 Overview
 
This week's training centered on understanding how weak passwords and outdated hashing methods can be cracked, and why that knowledge matters for building stronger defenses. The labs walk through extracting hashes from protected files and using both command-line and GUI tools to recover passwords via dictionary attacks.

## 🛠️ Tools Used
 
- **John the Ripper (JTR)** — command-line password cracking tool used for dictionary attacks
- **Johnny** — GUI front-end for JTR, used to visualize the cracking process
- **pdf2john (via OnlineHashCrack.com)** — converts password-protected PDFs into a crackable hash format
- **Networkwalks Hash Calculator** — web-based tool for generating and inspecting hashes
- **Networkwalks Password Cracker** — web-based tool reinforcing the same cracking concepts
## 🎯 Key Takeaways
 
- How to extract a crackable hash from a password-protected PDF
- How dictionary attacks work in practice, and why weak passwords fail quickly
- The difference between command-line (JTR) and GUI (Johnny) workflows for the same task
- Why understanding password-cracking techniques is essential for defenders — you can't properly advise on password policy, hashing standards, or MFA without understanding how attackers break weak credentials
## ⚠️ Disclaimer
 
All labs were performed strictly for educational purposes, using training-provided password-protected PDF files supplied by Networkwalks. No unauthorized access, real-world credentials, or third-party systems were targeted.
